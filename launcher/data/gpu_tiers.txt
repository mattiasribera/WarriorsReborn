# GPU tier table: the launcher's recommended graphics preset (src/gpu.h gpu_tier).
# Embedded into the launcher at build time. Raise `version` on every change: a stored detection
# (gpu_* keys in the profiles file) is recomputed when the table version changes.
#
# Tiers: T0 -> Performance, T1 -> Balanced, T2 -> Quality, T3 -> Quality (T3 is where a future
# Ultra preset goes). Integrated graphics are T0 whatever the table says, software renderers
# are never chosen.
#
# Rules, the first match wins:
#   <tier> <vendor> name <pattern>    the card's name, lower case, without (R)/(TM) and a trailing
#                                     driver code name; the pattern matches anywhere in it:
#                                     # one digit, ? one character, * any run
#   <tier> <vendor> id <lo>-<hi>      the PCI device ID (hex), for a card reported without a name
#   demote <vendor> name <pattern>    after a name/id match: one tier lower, not below T1
#                                     (laptop parts)
# vendor: nvidia (0x10de), amd (0x1002), intel (0x8086) or any.
# No match: the memory rule (under 4 GB T1, 4-8 GB T2, 8 GB and up T3). A card with under
# 3.5 GB is at most T1; a card without BC texture support is T0.
# Rough performance anchors: T1 ~ GTX 1050-1650, T2 ~ RTX 2060, T3 ~ RTX 3070 and up.
