# Download warnings

English first, Spanish below. / Primero en inglés, el español más abajo.

## If your browser or Windows blocks the download

WarriorsReborn is not code-signed yet, and each new version starts with no download history. So browsers and Windows may warn about it or hold the zip back. The source is public and every release is built from it by GitHub Actions. You can check the zip against `SHA256SUMS.txt`.

**Chrome:** if it says the file "isn't commonly downloaded" or "may be dangerous", open Downloads (Ctrl+J) and choose **Keep**.

**Edge:** open Downloads (Ctrl+J), hover over the file, click **⋯**, then **Keep**. Then click **Show more** and **Keep anyway**.

**Windows Defender / SmartScreen:** if a blue "Windows protected your PC" screen appears when you start the launcher, click **More info**, then **Run anyway**. If Defender removes a file after unzipping, open **Windows Security**, go to **Virus & threat protection**, then **Protection history**, select the item, and choose **Allow**. Then unzip again.

Why it happens: to run the original Xbox game, the program loads and patches the game's own code in memory. Antivirus heuristics sometimes mistake that for malware. We report each release to Microsoft and Google as a false positive.

## Si el navegador o Windows bloquea la descarga

WarriorsReborn todavía no tiene firma digital, y cada versión nueva arranca sin historial de descargas. Por eso los navegadores y Windows pueden advertir o retener el zip. El código es público y cada versión se compila desde él con GitHub Actions. Podés comprobar el zip con `SHA256SUMS.txt`.

**Chrome:** si dice que el archivo "no se descarga habitualmente" o que "podría ser peligroso", abrí Descargas (Ctrl+J) y elegí **Conservar**.

**Edge:** abrí Descargas (Ctrl+J), pasá el mouse sobre el archivo, hacé clic en **⋯** y después en **Conservar**. Luego hacé clic en **Mostrar más** y en **Conservar de todos modos**.

**Windows Defender / SmartScreen:** si al abrir el launcher aparece la pantalla azul "Windows protegió tu PC", hacé clic en **Más información** y después en **Ejecutar de todas formas**. Si Defender borra un archivo al descomprimir, abrí **Seguridad de Windows**, entrá en **Protección contra virus y amenazas** y después en **Historial de protección**. Elegí el elemento, tocá **Permitir** y volvé a descomprimir.

Por qué pasa: para correr el juego original de Xbox, el programa carga y parchea en memoria el código del propio juego. Algunos antivirus lo confunden con malware. Cada versión la reportamos a Microsoft y Google como falso positivo.
